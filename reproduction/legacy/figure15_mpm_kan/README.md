# Source benchmark 15

This module preserves the SeaKAN implementation for Figure 15 of Zhu et al. (2024), [Ocean Engineering 314, 119733](https://doi.org/10.1016/j.oceaneng.2024.119733). See [the reproduction guide](../../README.md) for the manuscript figure numbering, dependencies, checkpoint replay and data provenance. The source runner supports training and evaluation from a checkout.
